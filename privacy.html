Privacy Policy

Last updated: 28 September 2026

Concerts Playlist is a personal, non-commercial project that lists upcoming concerts in Gent and Brugge and keeps matching YouTube Music playlists up to date. The source code is public at github.com/gillesgerlo/gent-concerts-playlist.

Visitors to this website

These pages are static files hosted on GitHub Pages. They contain no analytics, cookies, trackers or forms, and this project collects no personal data from visitors. GitHub, as the host, may keep standard server logs; see the GitHub Privacy Statement.

Google / YouTube account access

The project's Google OAuth app is used only by its owner, to sign in to the owner's own YouTube account. It uses the YouTube Data API solely to find, create and edit the owner's "Upcoming Concerts" playlists (adding and removing tracks). It does not access anyone else's account, and it does not read, store or share any other YouTube or Google data. The only credential kept is the owner's own OAuth refresh token, stored privately and never published.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
